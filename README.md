## Repository organization

Each folder is an independent learning unit. New folders should include:

```text
Goal
Technologies
How to run
What I learned
Known limitations
```

## Promotion rule

A study exercise should move into a dedicated repository only after it has a coherent problem, setup guide, tests where relevant, documented decisions and a clear completion criterion.
